# Fake-Dia PWA Demo

Це навчальний демо‑проект, який показує, як зробити простий PWA, щоб імітувати поведінку "встановленого" застосунку (режим standalone), та приклад Telegram-бота, що надсилає код і посилання.

Quick steps

1. Запустіть локально: відкрийте `index.html` в браузері або хостьте через простий HTTP сервер:

```bash
python -m http.server 8000
# або
npx http-server . -p 8000
```

2. Відкрийте `http://localhost:8000`.
3. Для локального тесту використайте код `0000` або додайте `?code=1234` до URL.
4. Щоб зробити сайт PWA і встановити його: у Chrome відкрийте меню ⋮ → "Додати на головний екран" або використайте банер "Install".

Деплой на GitHub Pages

1. Створіть репозиторій на GitHub і додайте файли.
2. У налаштуваннях репозиторію увімкніть GitHub Pages (main branch / root).
3. Після деплою URL буде `https://<your-username>.github.io/<repo>/` — згенеруйте посилання з кодом у параметрі `?code=0000`.

Telegram bot

- `bot.py` — простий приклад, який надсилає код та посилання. Для запуску потрібен токен бота.
